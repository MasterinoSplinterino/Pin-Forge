# Настройки печати

Подобрано под мелкий рельеф: буквы шириной 0.5–1 мм, высота рельефа 0.4–0.5 мм.
Источник правды — функция `orcaConfig()` в `index.html`; при экспорте `.3mf`
эти значения зашиваются в проект. Таблица ниже — то же самое словами,
чтобы можно было выставить руками.

Слайсер: OrcaSlicer. Названия полей — как в интерфейсе.

## Качество

| Параметр | Сопло 0.4 | Сопло 0.2 |
|---|---|---|
| Layer height | 0.08 | 0.08 |
| First layer height | 0.2 | 0.12 |
| Default line width | 0.42 | 0.25 |
| Outer wall | 0.40 | 0.22 |
| Inner wall | 0.45 | 0.25 |
| Top surface | 0.40 | 0.22 |
| First layer | 0.5 | 0.28 |

Слой 0.08 выбран не ради красоты, а чтобы высота рельефа делилась нацело:
0.48 мм = 6 слоёв. Дробное число слоёв слайсер округляет как попало.

## Precision

| Параметр | Значение | Зачем |
|---|---|---|
| Slice gap closing radius | 0.01 | по умолчанию 0.049 — заращивает узкие просветы букв |
| Resolution | 0.005 | контуры букв не упрощаются в многоугольники |
| X-Y hole compensation | +0.05 | контрформы «e», «o» не затягивает |
| X-Y contour compensation | −0.05 | наружный контур поджимается, буквы не сливаются |
| Elephant foot compensation | 0.2 | обязательно при печати лицом вниз |
| Precise wall | вкл | точный наружный размер |

Пара компенсаций работает в связке: отверстия чуть шире, контур чуть уже.

## Wall generator

| Параметр | Значение |
|---|---|
| Wall generator | **Arachne** |
| Minimum wall width | 85% (0.34 мм при сопле 0.4) |
| Minimum feature size | 25% (0.1 мм) |
| Wall loops | 3 |
| Walls printing order | Inner/Outer |
| Only one wall on top surfaces | **выкл** |
| Avoid crossing walls | вкл |

Arachne критичен: штрих 0.85 мм это 2.02 линии, Classic положит две и полезет
затыкать остаток gap-fill'ом — буквы пойдут волнами. Arachne растянет две
линии до 0.425 и обойдётся без мусора.

`Only one wall on top surfaces` выключен намеренно: верх буквы шириной
0.85 мм — ровно две линии, опция оставит одну и провалит середину.

## Заполнение и оболочки

| Параметр | Значение |
|---|---|
| Top shell layers | 8 (0.64 мм при слое 0.08) |
| Bottom shell layers | 5 |
| Sparse infill density | 25% |
| Sparse infill pattern | Gyroid |
| Infill/wall overlap | 15% |
| Apply gap fill | **Nowhere** |
| Filter out tiny gaps | 0.2 |

30% перекрытия выдавливает заполнение в наружную стенку, на боках букв
проступает рябь — отсюда 15%.

## Ironing

| Параметр | Значение |
|---|---|
| Ironing type | All top surfaces |
| Flow | 10% |
| Speed | 30 мм/с |
| Spacing | 0.12 |

Верхушки букв становятся глянцево-плоскими, по ним ровно ложится хром
или Rub'n'Buff.

## Шов

| Параметр | Значение |
|---|---|
| Seam position | Aligned |
| Scarf joint seam | External (на внешней стенке) |
| Scarf min length | 10 мм |

На буквах в пару миллиметров шов заметнее всего; скошенный стык его прячет.

## Скорости, мм/с

| Параметр | Значение |
|---|---|
| Outer wall | 50 |
| Inner wall | 100 |
| **Small perimeters** | **40** |
| **Small perimeters threshold** | **2 мм** |
| Top surface | 60 |
| Gap infill | 80 |
| Sparse infill | 200 |
| Internal solid infill | 150 |
| First layer | 25 |

Порог мелких периметров — самое важное поле во всём списке. По умолчанию
там 0, то есть опция выключена, и контрформы букв печатаются на полной
скорости. С порогом 2 мм все просветы в «e», «o», «n» едут на 40 и успевают
лечь ровно.

200 мм/с по внешней стенке при слое 0.08 означает, что буква проходится
за доли секунды и не успевает остыть — отсюда 50.

## Ускорения, мм/с²

| Параметр | Значение |
|---|---|
| Normal printing | 3000 |
| Outer wall | 1500 |
| Inner wall | 2000 |
| Top surface | 1500 |
| First layer | 500 |

У K1C штатное ускорение за 10000. На буквах шириной пару миллиметров
принтер успевает разогнаться и затормозить внутри одной буквы: углы
скругляются, на прямых звон.

## Охлаждение

Живёт в настройках **филамента**, не процесса. Иконка катушки → Cooling.

| Параметр | Значение |
|---|---|
| Fan speed min / max | 100 / 100 |
| Slow down if layer time < | 15 с |
| Fan full speed if layer time < | 60 с |
| Disable fan for first N layers | 1 |

Если печатаешь одну копию — слои крошечные и времени на остывание нет.
Ставь 3–6 копий на стол, тогда охлаждение получается естественным.

## Филамент

**PLA.** PETG для такой мелочи не годится: тянет сопли через просветы между
буквами, даёт наплывы на коротких периметрах, округляет углы.

Сопло 205–210 (на 5–10° ниже обычного — расход мизерный, филамент
перегревается), стол 55–60. Филамент сухой, без CF и вторички.

## Ориентация

**Буквы выпуклые, лицом вверх** — проще, без поддержек. Минус: шов на
каждой букве и текстура верхнего слоя (частично лечится ironing).

**Буквы врезанные, лицом вниз** — лицевая поверхность становится первым
слоем на гладкой PEI, то есть зеркальной, без швов и линий слоя. Буквы —
чёткие колодцы под заливку краской. Лучший результат, но требует
elephant foot compensation и ровного стола.

Поддержки нужны только если крепление сделано площадкой с нависающим
краем. Вариант «только гнездо, без площадки» не требует их вовсе.

## Проверка перед печатью

1. Прогнать превью по слоям на высоте букв: не слиплись ли просветы
   в «e» и «o». Если слиплись в превью — на столе точно не разлепятся.
2. Поставить 3 копии с масштабом 100 / 115 / 130%, чтобы за одну печать
   увидеть, с какого размера контрформы открываются.
3. Проверить в генераторе панель «Проверка на пропечатку»: минимальный
   штрих должен делиться на ширину линии нацело.

## Пауза для закладки магнита

Если в генераторе включена крышка над вставкой, памятка в архиве пишет
высоту паузы. В Orca: правый клик по слою в превью → Add pause. Кладёшь
магнит, продолжаешь, принтер замостит потолок мостом.

Полярность: вклеивать или закладывать магнит только в паре с ответным,
тогда полюс выставится сам. Если магнитов два — оба одним полюсом наружу.
